/* PERFORMANCE BUDGET (engineering targets — NOT field measurements yet;
   real Lighthouse/field numbers still need a deployed host to be meaningful) */
LCP:  <= 2.5s   (hero is text; hero portrait <= 150px, fetchpriority high)
INP:  <= 200ms  (scroll work off main thread: wash via animation-timeline, pins only in GSAP)
CLS:  <= 0.1    (all media have aspect-ratio / intrinsic sizes; content-visibility on long rows)
Long tasks: < 50ms (init is measurement + listeners; WebGL is ONE global canvas,
single context, max 3 hero displacement planes, DPR-capped at 1.5)
Third-party on first load: pinned GSAP 3.12.5 + Lenis 1.1.14 + Google Fonts only.
WebGL: NEVER in the first viewport on mobile; displacement is fine-pointer-only,
3 hero moments max, global kill switch (context failure = silent DOM stills).

/* MOTION CONTRACT */
- prefers-reduced-motion: everything settles to a readable end state (no preloader,
  no autoplay, no cursor, no displacement, no view transitions, static section paint).
- No-JS / CDN-failure: page fully readable; videos show posters; preloader never traps.
- Preloader: <= 1.4s, typed real line, real font+image progress, skipped when cached,
  on slow connections, or under reduced motion.

/* ORIGINAL INSTRUMENTS (from the retired hand-built build, preserved for the
   record — see /lab/ for the experiments that live on) */
- SEAMS/PAGES: puzzle-piece hero — scroll velocity or tap bursts 24 canvas tiles,
  springs reform them; SCATTER/REFORM button for touch/keyboard; static image
  under reduced motion or no-JS. No new WebGL (canvas-2D only).
- THREE DEEP: three parallax layers (gold wash, court lines, symbols) — pointer
  drift capped 4/8/12px on fine pointers, scroll drift on coarse; static under
  reduced motion.
- THE FAN: all ten volumes fanned — arrows/keys/buttons browse, any book opens
  its existing catalog modal; static screenshot fallback with no-JS.
- COURT/BOOK: inline SVG line drawing that draws itself on scroll; REPLAY redraws;
  fully drawn under reduced motion or no-JS (replay hidden when reduced).

/* HONESTY CONTRACT */
- Every book title is a real published book. Only The Spirit of Solomon shows real
  cover art; the other nine are labeled house-style cards until final art exists.
- No invented stats, awards, prices, or achievements anywhere.
- The Spirit of Solomon modal links its verified Books-A-Million product page
  (paperback $12.99, ISBN 9798316662975 — verified 2026-09-29) with the publisher's
  own description. The other nine volumes keep genuine search-engine links —
