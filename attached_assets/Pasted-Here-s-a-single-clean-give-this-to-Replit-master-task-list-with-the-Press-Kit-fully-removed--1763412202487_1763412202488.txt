## TASK 3 – UNIFY & SIMPLIFY CONTACT FORMS

We want **one** contact form logic reused everywhere.

1. **Create a reusable `<ContactForm />` component**

   * Fields:

     * Name (required)
     * Email (required)
     * Organization (optional)
     * Subject (short text)
     * Message / Details (textarea)
     * Inquiry Type (radio or select, required):

       * Speaking / Appearance
       * Press / Media
       * Book / Author
       * Basketball / Athlete
       * Other
   * Add basic front-end validation for required fields.

2. **Use `<ContactForm />` on:**

   * `/contact` → standard usage.
   * `/speaking` → remove any custom form and embed `<ContactForm />`, with default Inquiry Type = “Speaking / Appearance” if possible.
   * Anywhere else you had a custom form (old Press Kit page, etc.) → either:

     * Remove the form entirely and link to `/contact`, or
     * Embed `<ContactForm />` with a pre-selected Inquiry Type.

3. **Remove old/duplicate forms**

   * Delete legacy form markup and handlers that are no longer used to reduce confusion.
